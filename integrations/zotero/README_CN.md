# TeXGlot for Zotero

[English](README.md) · **简体中文** · [返回 TeXGlot](../../README_CN.md)

在 Zotero 中发起论文翻译，把译文保存为文献附件，并直接左右对照阅读。插件负责连接本机 TeXGlot；源码获取、模型调用和 PDF 编译由 TeXGlot 完成。

## 可以做什么

- 右键翻译 arXiv 论文，也可选择附在条目下的 LaTeX 源码工程。
- 自动识别 arXiv 版本，无需先给 Zotero 条目手填 `v1`、`v2`。
- 优先复用 Zotero 或 TeXGlot 文献库中同版本、同语言的已有译文。
- 在一个 Zotero 标签页中显示原文与译文，支持双向同步滚动和拖动分隔线。
- 将译文保存为原条目的子附件，保留原 PDF 和已有批注。
- 通过文献列表中的 TeXGlot 状态图标识别已有译文及任务状态。

## 安装

### 1. 准备 TeXGlot 和 Zotero

需要 **Zotero 9**，以及与插件配套的 **TeXGlot App 或本地服务**。插件自身不包含模型或编译器，不能单独完成翻译。当前实机验证环境为 macOS 上的 Zotero 9.0.6；其他平台的插件交互尚未完成同等验证。

从 [TeXGlot Releases](https://github.com/Mengqi-Lei/texglot/releases) 获取包含插件的版本，使用该 Release 配套的桌面安装包和 `texglot-zotero-<版本>.xpi`。安装方法见[主程序指南](../../README_CN.md#快速开始)。

**插件 1.0.0 需要 TeXGlot 1.2.0 或更新版本。** 请从 [v1.2.0 Release](https://github.com/Mengqi-Lei/texglot/releases/tag/v1.2.0) 下载配套安装包和 `texglot-zotero-1.0.0.xpi`。旧版 1.1.3 App 不包含文献库复用接口，不能只更新插件；开发者可按[开发说明](docs/development.md)自行构建。

打开 TeXGlot，在“模型设置”中配置服务商、模型和 API key，测试连接并保存。使用本地模型时，沿用 TeXGlot 的本地模型配置。API key 不需要再填进 Zotero。

### 2. 安装 XPI

1. 在 Zotero 中打开 **工具 → 插件**。
2. 点击插件管理器右上角的齿轮按钮，选择 **Install Plugin From File… / 从文件安装插件**。
3. 选择下载的 `.xpi` 文件，按 Zotero 提示完成安装；如果提示重启，就重启 Zotero。
4. 回到文献库，右键任意论文，应能看到 **“使用 TeXGlot 翻译并对照阅读”**。

更新插件时同样从文件安装新 XPI；不必先卸载或删除文献附件。更新主程序后，需要退出旧 App 并重新打开，运行中的服务才会切换到新版。

### 3. 保持本地服务运行

开始翻译或从 TeXGlot 文献库导入译文时，保持同一台电脑上的 TeXGlot 运行。源码或 CLI 用户可运行 `texglot --serve`。插件会查找默认本地服务地址 `127.0.0.1:8765`，并兼容桌面版常用的备用端口 `8766`。

如果 App 和 CLI 使用了不同的数据目录，插件只会查询当前连接服务的文献库，不会合并另一份库。

## 第一次翻译

1. 在 Zotero 中选中论文的**文献条目**。通常直接使用 Zotero 导入的 arXiv 条目即可，不需要修改版本字段。
2. 右键选择 **“使用 TeXGlot 翻译并对照阅读”**。
3. 插件识别来源与版本。如果存在多个无法区分的原文 PDF，会让你选文件；能够自动确定时不会弹框。
4. 已有可用译文时直接打开或导入；已有任务正在处理时继续跟踪该任务；都没有时才新建翻译。
5. 翻译完成后，译文以 **`[TeXGlot] 简体中文 · arXiv …`** 的名称加入原条目，并打开左右对照。

进度会反映在 TeXGlot 状态列，具体处理记录、停止和继续/重试操作在 TeXGlot App 的任务详情中查看。保持 Zotero 开启可让插件在完成后自动导入；如果中途关闭 Zotero，之后再次使用同一右键命令，会查找已有结果或正在执行的任务。

当前右键入口默认翻译为**简体中文**，开启**上下文引导**；模型、API 和并发设置使用 TeXGlot 的配置。插件暂未提供独立的翻译选项面板，其他目标语言请通过 App 或 CLI 发起。

### 哪些论文可以使用

| Zotero 中的内容 | 如何使用 |
| --- | --- |
| 有 arXiv 链接或编号的论文 | 选中文献条目后使用右键命令；翻译仍要求 arXiv 提供 LaTeX 源码。 |
| 只有不带 `vN` 的 arXiv 编号 | 可以使用，插件会读取 PDF 首页、附件信息，必要时查询官方版本。 |
| arXiv 条目没有本地 PDF | 可以使用，插件会获取与翻译任务配套的原文。 |
| 本地 LaTeX 工程 | 将 `.tex` 或 `.zip`、`.tar`、`.tar.gz`、`.tgz`、`.gz` 源码包附到文献条目下，选中**该源码附件**后使用右键命令。含图片和模板的论文应上传完整工程包。 |
| 只有会议、期刊 PDF，没有 arXiv 编号或 LaTeX 源码 | 当前不能直接翻译。若确认存在同一论文的 arXiv 版本，可在条目“其他”中加入 `arXiv:编号`，再使用插件。 |

PDF 用来识别论文和作为阅读原文，并不意味着插件已经支持 PDF 反向解析或 OCR。也不会仅根据相同标题猜测另一篇论文。

## 对照阅读

### 原文、译文和左右对照怎么打开

| 想要的阅读方式 | 操作 |
| --- | --- |
| 左右对照 | 默认双击已有唯一对应译文的**文献条目**；也可使用右键“使用 TeXGlot 翻译并对照阅读”。 |
| 只看原文 | 展开文献条目，双击原文 PDF 子附件。 |
| 只看译文 | 展开文献条目，双击 `[TeXGlot] …` 译文 PDF 子附件。 |
| 双击始终打开普通单篇 PDF | 在文献条目右键菜单中将 **“TeXGlot：双击默认左右对照”** 切换为关闭。需要对照时仍可使用翻译并对照阅读命令。 |

双击开关会保留到下次启动。没有对应译文、原文不确定或存在多个可能译文时，双击保留 Zotero 的普通行为；不会自动开始一项付费翻译。要打开某份特定译文的对照，可选中该译文附件，再使用右键的翻译并对照阅读命令。

### 分屏中的控件

- **分隔线**：拖动中间分隔线，调整两侧宽度。
- **同步：开 / 关**：开启时滚动任意一侧，另一侧跟随；关闭后可以分别定位。
- **定位基准：译文 / 原文**：决定开启同步或重新对齐时跟随哪一侧；不限制只能从这一侧滚动，也不是左右互换按钮。
- **每侧阅读工具栏**：先点击要操作的一侧，再使用搜索、缩放、翻页或批注工具。工具栏中矩形里的左右箭头是 Zotero 的**重置缩放**按钮，不会交换原文和译文。

当前 Zotero 分屏依据页码与页内位置同步，不保证逐句对齐。翻译后分页可能变化；需要精确比较某一段时，可以关闭同步后分别定位。两侧的批注分别保存在各自的 Zotero 附件中，不与 TeXGlot App 的批注互相覆盖。

## 版本与译文复用

### 不需要手填版本号

明确选中的 PDF 优先；选择父条目时，插件检查候选原文，优先采用实际 PDF 首页的 arXiv 版本戳，再使用附件信息。父条目只保存基础编号是正常情况。

多个已确认版本属于同一论文时，默认选本地最高版本；无法区分的文件由你选择。若本地 PDF 版本仍不明，插件查询官方版本并询问是否使用其配套原文。确认后会另加配套原文，保留旧 PDF 和批注；取消不会创建任务。

确定版本后，获取源码、匹配译文和建立对照使用同一个完整版本。不同论文编号冲突时不会自动拼成一对。

### 已在 App 翻译过，还会再扣一次额度吗

普通右键命令依次查找：

1. 当前 Zotero 条目下可用的对应译文。
2. 当前 TeXGlot 文献库中**同完整版本、同目标语言**的可用结果，包括从 App、网页、CLI 或插件创建的任务。
3. 匹配的正在执行的任务。
4. 没有以上结果时，才创建新翻译。

复用完整结果不调用模型。模型或上下文设置后来改变，也不会自动使已有译文失效。只有想使用当前设置重新翻译时，才选择 **“使用 TeXGlot 重新翻译（保留已有译文）”**；这会创建新任务并产生正常模型用量。

版本或语言不同、结果文件损坏或缺失、旧任务没有记录完整版本时，不能保证复用。源码包依据内容和主文件选择匹配，不按文件名匹配。无法安全复用的失败任务可在 App 中继续/重试，利用其中已完成的段落缓存。

## 文献列表中的状态图标

TeXGlot 列首次添加在标题旁，可从列标题的右键菜单勾选显示或隐藏，也可拖动调整位置。表头使用 TeXGlot 的 TG 图标；将鼠标停在某行图标上可以查看说明。

| 图标 | 含义 |
| --- | --- |
| 绿色勾号 | 此 Zotero 条目已有 TeXGlot 译文附件。 |
| 蓝色时钟 | 当前插件会话中有任务正在处理。 |
| 黄色警告 | 任务或译文需检查；悬停查看具体原因。 |
| 浅色横线 | 此条目还没有识别到 TeXGlot 译文附件。 |

**状态列不会预先扫描整个 TeXGlot 文献库。** 一篇论文可能已在 App 翻译完成，但 Zotero 中还显示横线；首次右键操作会查找并导入已有结果，之后显示勾号。已保存的译文状态无需启动 App 即可显示。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 没有 TeXGlot 右键菜单 | 确认 Zotero 版本和插件启用状态，选择文献条目或其附件；按安装提示重启 Zotero。 |
| 无法连接本地服务 | 启动同机的 TeXGlot 并等待界面加载，再试一次。 |
| 提示更新 TeXGlot | 更新配套的 App 和 XPI，并退出旧 App 后重新打开。插件不会为了兼容旧服务而偷偷新建翻译。 |
| 提示没有可识别来源 | 检查是否有正确的 arXiv 信息或完整 LaTeX 工程；一个普通 PDF 附件本身不够。 |
| 有多个原文或译文 | 选中要使用的具体附件后再操作，避免由标题猜测对应关系。 |
| 编译或模型调用失败 | 在 App 中查看任务详情和处理记录，修正配置或来源后“继续 / 重试”。 |
| 翻译完成，但 Zotero 没有附件 | 保持 App 运行，再次使用普通右键命令，复用已完成结果并重试导入。 |
| App 已完成却仍新建任务 | 核对完整版本、目标语言、运行中的 App 是否已更新，以及 App/CLI 是否使用不同数据目录。 |
| 双击没有进入对照 | 检查双击开关；确认双击的是父条目，并且两份本地 PDF 存在且关系明确。 |
| 两侧文字没有严格对齐 | 页数不同是正常现象；可关闭同步分别定位，当前不提供逐句对齐。 |

已下载到 Zotero 的原文和译文可以在 TeXGlot 关闭时阅读；新翻译、从核心文献库首次导入或补回丢失文件仍需要服务运行。其他阅读器插件的功能若在分屏中表现不同，可以打开单个 PDF 使用 Zotero 普通阅读器。

## 数据与开发

模型密钥和翻译缓存由 TeXGlot 管理，插件不另存模型密钥。导入 Zotero 的附件按你已有的 Zotero 同步设置同步；卸载插件不会主动删除文献、译文附件或批注。两端的数据目录与备份方式见[主程序数据说明](../../README_CN.md#数据与隐私)。

插件和核心共用本仓库，按独立 `.xpi` 包分发，采用 [Apache 2.0](../../LICENSE)。构建、测试及接口说明见[开发文档](docs/development.md)。
