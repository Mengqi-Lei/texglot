# 能力边界与排错

[English](troubleshooting.md) · **简体中文** · [返回 README](../README_CN.md)

TeXGlot 翻译的是 **LaTeX 源码**，不支持上传任意 PDF 或扫描文档直接翻译。arXiv PDF 链接仅用于识别可获取源码的论文。

| 情况 | 检查方向 |
| :--- | :--- |
| arXiv 导入失败 | 确认论文提供可下载的 TeX 源码，且本机可以连接 arXiv。 |
| EPS 插图 | 安装可选的 Ghostscript 后继续任务，程序会保留 EPS 原图并生成供编译使用的 PDF 副本。详见[桌面指南](desktop_CN.md)。 |
| minted 提示需要 shell-escape | 程序会在确认工程未使用 minted 时移除其加载项。确实使用了代码环境或冻结缓存时保留源码；请提供与编译环境匹配的完整冻结缓存，或改用 listings。编译仍保持禁用外部命令执行。 |
| PDF 插图存在却无法载入 | 对编译器确认的可恢复索引损坏，程序会尝试修复并在预处理工程中保留 `.texglot-original` 备份。文件缺失、加密或不可修复时会提示具体文件；请补齐文件、检查引用路径或重新导出图片。不会生成占位图来掩盖缺失内容。 |
| PSTricks／PostScript 绘图 | 默认 Tectonic 安装包不包含完整 PostScript 工具链，建议先转换为 PDF 插图。另装完整 TeX 时还需匹配的输出驱动与外部工具，并检查图形是否实际显示，不能仅依据退出状态。 |
| acmart 提示找不到 `libertinusmath-regular` | 自动规范该已知打包字体的文件名，优先保留工程自带字体及显式字体路径、扩展名设置。更新后点击继续 / 重试，可刷新预处理源码并复用有效译文。 |
| `amssymb` 与 `unicode-math` 冲突 | 根据具体报错及实际编译加载记录，为一处可明确定位的宏包调用添加条件保护：已加载 `unicode-math` 时跳过 `amssymb`，否则仍执行原调用。代码示例、宏包选项与顺序均保留；无法明确定位时保留编译错误供检查。 |
| 编译失败 | 补齐 `.sty`、图片与参考文献，查看编译日志；依赖 shell escape 或缺失外部工具的模板可能不适用。设置中可以选择已安装的 XeLaTeX/LuaLaTeX。 |
| API 报错 | 检查地址、地域、模型权限、余额和限流；必要时降低并发或增加超时。 |
| 网关需要组织或会话请求头 | 在翻译设置 → 高级设置 → 额外请求头中填写 JSON，例如 `{"x-org-id":"org_..."}`。不编辑则保留当前地址的保存值；新对象会整组替换，空对象或“清除请求头”后保存会删除。手动修改地址会清空输入，选回已保存服务可恢复该服务自己的配置。值不回显，测试连接不会保存。值首尾空格会自动去除。最多 16 项、每值 4096 字符、总计 16 KiB；仅支持可打印 ASCII，不允许覆盖 Authorization、Host 或传输控制字段。DeepL 不使用此功能。 |
| 官方 OpenAI / Claude 返回 HTTP 400 | 在“自定义”中分别填写 `https://api.openai.com/v1` 或 `https://api.anthropic.com/v1`，并填写该账户可用的完整模型名。使用 Chat Completions 兼容接口，不填写原生 `/responses` 或 `/messages` 地址。程序适配 OpenAI 输出长度参数；官方明确拒绝温度设置时自动使用模型默认值重试，不改写保存的温度偏好。其他 400 会显示脱敏后的具体原因；反馈时提供模型名、Base URL、版本和错误提示，无需提供密钥。 |
| 导言区单独存放，提示找不到主文件 | 已支持主文件通过 `\input` / `\include` 引用导言文件的工程。更新后点击继续 / 重试，无需把导言区复制回主文件。动态生成文件名或用宏生成整个文档入口的工程，仍可能需要整理为明确的主文件和本地引用。 |
| 部分文字未翻译 | 检查任务警告，继续任务以重试失败段落。未知宏、作者信息和参考文献条目可能按规则保留原文。 |
| 模型推理过程混入译文 | 更新后点击继续 / 重试，程序会清理可识别的 LLM 响应封装及旧缓存中的对应内容，不完整回答会重试。原文引用的标签和有效译文缓存会保留。 |
| 原文和译文页数不同 | 翻译会改变文字长度和分页。优先按共同内容定位点同步，缺少定位点时退回页内位置；并非逐句对齐。 |
| 源码安装在前端构建阶段超时 | 本地构建超过 10 分钟会停止。检查输出；若目录访问卡住，将源码解压到普通本地项目目录后重新安装。依赖下载不受该构建超时限制。 |
| 找不到 `texglot` | 运行 `uv tool update-shell` 后重开终端，或在源码目录使用 `uv run python -m app.cli`。 |

不对图片内文字做 OCR 翻译或重绘。科研使用仍需人工检查译文，自动校验不代表每一句语义都正确。
