# 连续阅读与批注

在文献库点击「对照阅读」进入阅读器。原文和译文都可以纵向连续滚动，无需逐页切换。长论文只渲染视野附近的画布，页面离开视野后释放画布。

## 阅读与对照

- 默认开启「同步滚动」，优先根据原译文共享的章节、图表、公式和参考文献定位点建立对应，在相邻定位点之间估算位置，避免页高和分页差异沿整篇累积。不同语言的段落长短仍可能不同，这不是逐行对齐。PDF 缺少这些定位信息时，底栏会显示「按页码与页内位置同步」。
- 相同插图会额外核对图像内容与图号。在已匹配的图区域内，即使浮动排版改变了图与章节的先后顺序，也会定位到另一侧的同一张图；离开图区域后继续跟随正文定位点。因此，遇到重排插图时，另一侧可能跨页定位。
- 关闭同步后可以分别滚动。重新开启时，以译文侧当前内容为准，将原文重新定位到对应位置。
- 从单独原文或译文进入对照时，保留正在阅读的内容，并定位另一侧；之后是否继续联动沿用同步开关。离开对照时，保留所选一侧的位置。单侧原文与译文直接切换时，也会寻找当前内容的对应位置。
- 点击某一侧页面或该侧标题后，页码栏操作该文档。输入页码并回车，或用左右箭头按钮、键盘 `←` / `→` 跳页。
- 在 PDF 阅读区域按住 `Ctrl` 并滚动鼠标滚轮即可缩放：向上放大、向下缩小，范围为 50%–250%。也可使用顶部 `−` / `+`，点击百分比恢复适合宽度。普通滚轮仍用于连续阅读。
- 放大、缩小、打开批注侧栏和调整窗口尺寸时，保持当前内容在视口中的阅读位置。PDF 文档在视图切换时复用，仍只渲染附近页面。
- 页码输入框只有在编辑后才执行跳转；未修改便离开输入框不会跳到页首。
- 阅读位置、显示模式、同步开关和缩放自动保存。点击返回、重开页面后可继续上次阅读。

## 添加标记

- **选择文字**：拖选正文后出现颜色工具条，点击颜色添加高亮；也可添加下划线，或同时打开文字批注。
- **高亮 / 下划线工具**：先在顶部选择工具和颜色，之后每次拖选正文都会自动添加对应标记，适合连续标注。
- **便签工具**：点击页面任意位置放置便签，在右侧写下想法。
- 顶部「选择文字」可退出连续标记模式。`Escape` 优先关闭选中文字后的工具条。

## 管理批注

右上角「批注」打开列表。可按原文、译文筛选，或搜索引文和批注内容。点击条目跳到对应页面，查看或修改批注；点击页面上的高亮或便签也会打开编辑器。五种标记颜色均可更改。

文字批注会自动保存，也可点击「保存」。在保存完成前刷新，未发送的草稿会在重新打开该论文后恢复。遇到本地服务中断或其他窗口修改同一条批注时，会显示错误并保留草稿；重新连接并检查最新内容后再保存。

删除后可以立即「撤销」。与重生成前的 PDF 关联的旧批注会保留并显示「旧版本」，不会贴到新的 PDF 上。

## 文件与隐私

批注和阅读状态保存在每个任务的 `data/jobs/<id>/reader.json`（使用自定义数据目录时位于对应目录下）。未发送的文字草稿仅暂存在本机浏览器，成功保存后移除。

原文 PDF、译文 PDF、CLI 导出和 LaTeX 源码包都不包含 TeXGlot 的批注。批注不会发送给模型服务，也不会进入 Git 仓库。备份本地数据目录时会一同保留已保存的批注。

交互参考 [Zotero 官方阅读器文档](https://www.zotero.org/support/pdf_reader) 中的文字选择标记和独立存储方式，代码基于现有 PDF.js 阅读器独立实现。
