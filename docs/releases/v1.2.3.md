# TeXGlot 1.2.3 · Custom-format prose translation fixes

**English** · [简体中文](v1.2.3_CN.md)

Fix papers marked as completed while entire passages in their title, abstract or body remain untranslated. Author-defined formatting commands can wrap ordinary prose; previous versions could protect the entire argument as layout syntax instead of sending its text for translation.

## Changes

- Recognize explicitly defined `DeclareRobustCommand`, simple `def/gdef` formatting wrappers and their `let` aliases, making their prose translatable.
- Translate nested callouts and custom “icon = description” structures while preserving identifiers.
- Check actual parameter roles and continue protecting code, math, colors, dimensions and ambiguous redefinitions.
- Preserve TeX spacing units directly adjacent to title text, such as `\kern0.04emTitle`.
- Bind cache keys to the corrected segmentation boundaries and reuse existing translations that still match and pass validation.

## Validation

Verified PROWBench (`2610.02205`) end to end: **214 segments**, **33 translated pages**, and **102 substantial prose arguments** individually checked for translated Chinese content. Repeating the task through the packaged engine reused all 214 cached segments without additional translation usage. Representative PDF pages covering the title, abstract, body, tables and appendix were visually inspected.

The full macOS backend suite passed **966 tests, with 3 skipped**, including 25 new parameterized regression cases. This is not a sentence-by-sentence translation-quality assessment. Author names, proper terms, text inside formulas and text embedded in existing images retain their existing preservation behavior.

## Upgrade and recover

Install **1.2.3**, then quit and reopen the app or local service. For completed tasks with missing translations, choose **Reprocess** in task details; unfinished tasks can use **Resume / Retry**. There is no need to delete or reimport papers, and valid matching translations are reused from the cache.

Existing papers, settings, annotations and reading records are retained. The Zotero plugin remains **1.0.0**, with the same XPI as the previous release. Plugin users only need to update the TeXGlot app/core.
