# TeXGlot 1.2.9

Papers that load `subfigure` or `subfig` before an older `subcaption` can now pass the layout check. This fixes the failure reported for WorldCoder (arXiv 2402.12275v3).

## What changed

When the compiler reports this specific package conflict, TeXGlot retries with upstream `subcaption` 1.6b. The template keeps control of panel numbering, captions and cross-references. If the project supplies its own package or the commands really are incompatible, the error identifies the conflicting packages.

## Upgrading and retrying

Install the update, restart TeXGlot or its local service, open the failed task and select **Resume / Retry**. Zotero users get the fix through the same application or service update. The bundled Zotero plugin is version **1.0.0**.

## Verification

We reproduced the failure with 1.2.8 and retried the same WorldCoder task with the fix. The original compiled to 67 pages. A layout test with simulated Chinese text processed all 278 paragraphs and produced a 63-page PDF. All six figure references matched the original.
