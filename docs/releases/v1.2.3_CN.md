# TeXGlot 1.2.3 · 自定义格式正文漏译修复

[English](v1.2.3.md) · **简体中文**

修复部分论文显示“翻译完成”，但标题、摘要和正文仍残留整段英文的问题。作者定义的格式命令可能包住普通正文，旧版会将整段内容作为排版指令保护，导致没有送去翻译。

## 更新内容

- 识别显式定义的 `DeclareRobustCommand`、简单 `def/gdef` 格式包装器及其 `let` 别名，使其中的正文正常参与翻译。
- 修复嵌套提示框和自定义“图标 = 说明”结构中的漏译，仅开放说明文字，保留标识符。
- 按参数的实际用途判断可翻译内容，继续保护代码、公式、颜色、尺寸及存在歧义的重定义。
- 修复间距单位紧贴标题文字时被误翻译的问题，例如 `\kern0.04emTitle`。
- 新的分段边界会生成对应缓存键，继续复用仍匹配且通过验证的旧译文。

## 验证情况

使用 PROWBench（`2610.02205`）完成真实论文验证：处理 **214 个段落**，生成 **33 页译文**；逐项检查的 **102 处较长正文参数**均已翻译为包含中文的内容。打包引擎再次重试时，214 个段落全部命中缓存，没有新增翻译用量。抽查了标题、摘要、正文、表格和附录的 PDF 页面。

macOS 完整后端测试 **966 项通过、3 项跳过**，包括本次新增的 25 个参数化回归用例。该验证不代表逐句翻译质量评测；作者姓名、专有术语、公式内部文字及图片中已有文字仍按现有规则保留。

## 升级与恢复

安装 **1.2.3** 后退出并重新打开应用或服务。对于已经显示完成但存在漏译的任务，在任务详情中点击**重新处理**；未完成任务可点击**继续 / 重试**。无需删除论文或重新导入，仍有效的译文缓存会被复用。

已有论文、设置、批注和阅读记录继续保留。Zotero 插件仍为 **1.0.0**，使用与上一版相同的 XPI；插件用户只需升级 TeXGlot 应用／核心。
