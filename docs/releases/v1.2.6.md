# TeXGlot 1.2.6 · Official API compatibility and split-preamble projects

**English** · [简体中文](v1.2.6_CN.md)

This release fixes parameter compatibility with official OpenAI and Claude Chat Completions endpoints, and recognizes papers whose document class is declared in a separate preamble file, including PanoNav (`2511.06840`).

## Changes

- Use OpenAI's current output-token parameter while preserving the configured limit. If an official endpoint explicitly rejects a temperature setting, retry with the model default within the existing request limit and reuse that behavior for subsequent paragraphs. Saved preferences remain unchanged.
- Normalize official base URLs and keep previously saved keys matched to the same endpoint. Native `/responses` and `/messages` URLs receive an actionable compatibility-endpoint hint before sending a request. Third-party services retain their existing request behavior.
- Show bounded, redacted provider error details instead of only “HTTP 400”, with matching English interface messages.
- Detect document classes through referenced local preamble files. Exclude code examples, unused macro definitions, explicitly inactive branches and references outside the project; bound recursion and preserve main-file selection and language ranking.

## Validation

Local macOS verification passed **1,141 backend tests, with 3 skipped**, **27 frontend tests**, lint checks and the production frontend build. The skipped cases require standalone XeLaTeX or Windows.

PanoNav's official source is now identified automatically and compiles to a **9-page original PDF** without warnings. A synthetic Chinese typesetting preflight covers **79 segments** and produces 8 pages without warnings. API request, rejection, recovery, credential-isolation and diagnostic behavior are tested with mock responses. These checks do not use real OpenAI/Claude credentials or assess full-paper translation quality.

## Upgrade

Install **1.2.6**, quit and reopen TeXGlot or its local service, then use **Resume / Retry** on affected tasks. Official services can still be configured under **Custom** with `https://api.openai.com/v1` or `https://api.anthropic.com/v1` and an available Chat Completions-compatible model.

The Zotero plugin remains at **1.0.0**. Its existing XPI and update manifest are included; Zotero users should update the TeXGlot app/core.
