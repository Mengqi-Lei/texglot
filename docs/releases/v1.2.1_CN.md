# TeXGlot 1.2.1 · DeepL 翻译

[English](v1.2.1.md) · **简体中文**

TeXGlot 新增独立的 DeepL 翻译引擎。桌面版、CLI 和 Zotero 集成均可通过 DeepL API 翻译 LaTeX 论文，无需配置大语言模型。

## 更新内容

- 使用经过校验的 XML 占位符保护公式、引用和 LaTeX 结构。译文改变受保护结构时，进行有限次数的恢复处理，通过校验后再接收。
- 支持 DeepL API Free / Pro 接口、源语言选择和已有 DeepL 术语表 ID。以 `:fx` 结尾的 Free 密钥自动使用 Free 接口。
- 单独显示字符用量，与大模型的 token 统计区分；不同翻译引擎使用独立的段落缓存，重试保留已完成工作。
- 为限流、临时故障及额度耗尽提供明确提示和有限重试。
- 翻译设置中的字母占位图标改为随应用打包的 Qwen、DeepSeek、DeepL 品牌图标。

## 开始使用 DeepL

1. 升级至 TeXGlot **1.2.1**，退出并重新打开应用或本地服务。
2. 打开**翻译设置 → DeepL**，填写自己的 DeepL API key，测试连接后保存。
3. 新建翻译任务。CLI 可用 `--provider deepl` 选择引擎，详见 [CLI 使用说明](../cli.md)。

需要 DeepL API 账号；普通网页版翻译会员不能代替 API key。已有设置、文献、缓存和批注继续保存在原数据目录。Zotero 仍会优先复用匹配的完整译文；如果希望换一个引擎重新生成，请使用插件明确提供的重新翻译入口。

Zotero 插件保持 **1.0.0**，XPI 与上一版相同。已安装插件的用户只需升级 TeXGlot 应用／核心，即可使用 DeepL。详见[插件使用说明](../../integrations/zotero/README_CN.md)。
