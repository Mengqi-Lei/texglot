# TeXGlot 1.2.5 · ACM 模板兼容与译文输出清理

[English](v1.2.5.md) · **简体中文**

本版修复部分 ACM 模板在翻译前编译失败的问题，并在使用和缓存译文前清理模型响应中明确的推理封装。感谢 [origin-meta](https://github.com/origin-meta) 在 [Issue #4](https://github.com/Mengqi-Lei/texglot/issues/4) 和 [PR #5](https://github.com/Mengqi-Lei/texglot/pull/5) 中提供反馈与代码贡献。

## 更新内容

- 修正已知的 Libertinus 数学字体文件名不匹配，保留工程自带字体、显式字体查找规则与原文代码示例。
- 根据实际编译加载记录确认 amssymb / unicode-math 冲突，用条件加载恢复编译，保护跨文件代码示例、宏包选项与顺序及作者的传统数学分支。
- 清理 LLM 响应中明确的前置推理块和完整答案封装，保留原文引用的标签、JSON 字符串内容与公式两侧空格。不完整或存在歧义的响应进入有限重试。
- 清理并校验旧 LLM 缓存，成功后原子写回，仅对无效项重新翻译。DeepL 继续使用对应服务的处理逻辑。
- 重试旧任务时刷新预处理源码并复用有效译文，补齐英文日志和发布用原生组合检查。

## 验证

本地 macOS 验证中，后端 **1082 项通过、3 项跳过**，前端 **25 项通过**，代码检查和构建通过。跳过项需要独立 XeLaTeX 或 Windows 环境。发布用原生检查覆盖字体恢复、代码示例保护、推理输出清理，以及之前的 minted 和 PDF 插图修复。

报告中的论文 `2504.07717` 原文生成 12 页 PDF，无编译警告；合成中文排版预检覆盖 77 个段落，生成 11 页，无警告。真实 Tectonic 与模拟翻译接口的组合流程验证了 PDF、源码包和缓存中的输出清理。本轮未调用付费翻译 API，未进行模型全文译文质量评测。

## 升级

安装 **1.2.5** 后退出并重新打开 TeXGlot 或本地服务，对受影响任务点击**继续 / 重试**。程序会更新源码预处理、清理可识别的旧响应封装，并复用有效译文。

Zotero 插件继续使用 **1.0.0**，发布中包含现有 XPI 和插件更新清单。插件用户请升级 TeXGlot 应用／核心。
