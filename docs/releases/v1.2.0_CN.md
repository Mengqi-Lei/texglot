# TeXGlot 1.2.0 · Zotero 插件 1.0.0

[English](v1.2.0.md) · **简体中文**

TeXGlot 现在可以直接与 Zotero 配合使用：从文献库发起翻译、复用已有结果，并在 Zotero 原生阅读器中左右对照。本次还修复了两类可能在调用模型前就阻断论文处理的模板问题。

## Zotero 集成

- **从文献库翻译。** 右键处理 arXiv 论文或附加的 LaTeX 工程；译文保存为原文献条目的子附件。
- **先复用，再翻译。** 查询本机 TeXGlot 文献库中由 App、网页或 CLI 创建的结果，按完整 arXiv 版本及目标语言匹配；上传源码按内容和主文件选择匹配。已有任务继续跟踪，需要重新翻译时使用单独入口。
- **自动识别版本。** 读取 PDF 首页及附件信息，无需手填 v1/v2。本地版本无法核实时，提供使用官方版本及配套原文的继续选项，同时保留已有文件和批注。
- **在 Zotero 内阅读。** 原生分屏支持两侧滚动、拖动调整宽度、各自搜索和批注，并恢复阅读标签。双击具有唯一译文的条目默认进入对照，也可关闭此行为，恢复普通单篇阅读。
- **一眼查看状态。** TG 图标列显示已有译文、处理中或需检查，表头和插件菜单统一使用 TeXGlot 图标。
- **防止意外重译。** 旧核心不支持文献库复用时明确提示更新，不静默调用旧的新建接口。

![Zotero 内左右对照阅读](../assets/zotero-reader.png)

安装与使用步骤见 [Zotero 插件指南](../../integrations/zotero/README_CN.md)。

## 翻译修复

- 将确定性的目标字体预检与模型译文校验分开，修复字母、数字混合名称在翻译前被误判为源码还原失败的问题。
- 在统一的 XeTeX 兼容层处理 pdfTeX 专用日期和文件标识设置，保留科学正文、代码示例、诊断行号及未知命令的报错边界。

## 升级与兼容性

请同时安装 **TeXGlot 1.2.0 和插件 XPI**。更新后退出旧 App/服务并重新打开；仅修改源码或安装新 XPI，并不会替换正在运行的旧核心。设置、论文、段落缓存和批注保留在原数据目录。因模板问题停止的任务可以在更新后点击“继续 / 重试”。

插件当前面向 **Zotero 9**，实机交互验证使用 macOS Zotero 9.0.6。桌面引擎构建成功不代表其他操作系统或 Zotero 主版本的插件交互已完成验证。Zotero 分屏目前按页码和页内位置同步，不是逐句对齐。本版不包含任意 PDF 反向解析或 OCR 输入能力。新翻译按所选模型服务商正常计费；命中完整已有结果时不调用模型。

桌面安装包仍未获得 Apple 公证或 Windows 发布者证书，安装及更新方式见[桌面指南](../desktop_CN.md)。
