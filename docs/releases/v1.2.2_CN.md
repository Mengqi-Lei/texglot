# TeXGlot 1.2.2 · 自定义代码环境兼容修复

[English](v1.2.2.md) · **简体中文**

修复论文自定义代码框包含 Markdown 代码围栏或 LaTeX 示例时，在翻译前触发源码分段校验错误的问题。即使代码框定义在另一个源文件中，也能正确识别，使 **Harness²** 等论文完成翻译，并保留其中的代码与提示词示例。

## 更新内容

- 跨文件识别显式声明的 tcolorbox listing、listings 和 fancyvrb 原样代码环境。
- 在分段、编译预处理、字体兼容和排版调整中保留原样代码内容，避免示例中的命令干扰依赖分析或摘要提取。
- 普通文字框继续翻译，公式、引用、保护标记及模型生成格式的校验继续生效。
- 重试历史任务时更新预处理源码，继续复用已通过校验的段落译文。

## 验证情况

完整翻译验证了 Harness²（`2610.14224`，34 页）、Generate-on-Graph（`2404.14741v3`，20 页）和 SceneTok（`2602.18882`，30 页）。后两篇属于历史失败任务，本轮重新验证了已有兼容修复。三篇均无遗留失败段落，并检查了代码框内容和代表性 PDF 页面。

macOS 源码验证中，**941 项后端测试通过、3 项环境相关测试跳过**，另有 **25 项前端测试**、**19 项桌面端测试**通过。打包引擎检查覆盖包含自定义代码框的单文件及多文件 LaTeX 输入。

## 升级方法

安装 **1.2.2** 后，退出并重新打开旧应用或服务。已有失败论文可直接点击**继续 / 重试**，无需删除任务或重新导入。已有设置、论文、批注和有效段落缓存继续保留。代码及提示词示例保持原文语言。

Zotero 插件仍为 **1.0.0**，XPI 与上一版相同；已安装插件的用户只需升级 TeXGlot 应用／核心。
