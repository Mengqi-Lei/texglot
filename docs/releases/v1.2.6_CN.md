# TeXGlot 1.2.6 · 官方接口兼容与独立导言区识别

[English](v1.2.6.md) · **简体中文**

本版修复官方 OpenAI、Claude 的 Chat Completions 接口参数兼容问题，并支持将文档声明放在独立导言文件中的论文工程，包括 PanoNav（`2511.06840`）。

## 更新内容

- OpenAI 使用当前的输出长度参数，保留原有长度上限。官方接口明确拒绝温度设置时，在现有请求次数限制内按模型默认值重试，后续段落复用该兼容结果，不改写保存的偏好。
- 规范官方地址，让之前保存的密钥继续匹配同一端点。误填原生 `/responses` 或 `/messages` 地址时，在发请求前提示正确的兼容地址。第三方服务保持原有请求行为。
- 报错显示经过脱敏、长度限制的具体服务端原因，不再只显示“HTTP 400”，并补齐英文界面提示。
- 沿本地导言文件引用识别文档声明，排除代码示例、未执行的宏定义、明确不执行的分支及工程外引用；限制递归深度，保留主文件选择和语言排序。

## 验证

本地 macOS 验证中，后端 **1141 项通过、3 项跳过**，前端 **27 项通过**，代码检查及正式前端构建通过。跳过项需要独立 XeLaTeX 或 Windows 环境。

PanoNav 官方源码现在可以自动识别入口，生成 **9 页原文 PDF**，无编译警告。合成中文排版预检覆盖 **79 个段落**，生成 8 页，无警告。接口测试覆盖请求格式、拒绝后的恢复、密钥隔离与错误提示，使用模拟响应，未进行真实 OpenAI／Claude 密钥联调或全文翻译质量评测。

## 升级

安装 **1.2.6** 后退出并重新打开 TeXGlot 或本地服务，对受影响任务点击**继续 / 重试**。官方服务仍在**自定义**中配置，分别使用 `https://api.openai.com/v1`、`https://api.anthropic.com/v1`，并填写账户可用且支持 Chat Completions 的模型名。

Zotero 插件继续使用 **1.0.0**，发布中包含现有 XPI 与更新清单。插件用户请升级 TeXGlot 应用／核心。
