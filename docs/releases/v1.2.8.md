# TeXGlot 1.2.8

This release improves LaTeX compatibility for long papers and books, covering frozen code caches, bibliographies, prose extraction and float layout.

## Changes

- Use pinned upstream packages for diagnosed incompatibilities with minted 3 frozen caches and missing PSTricks/biblatex dependencies. Preserve project packages, code and figures; shell escape remains disabled.
- Rebuild outdated bibliographies from local BibTeX data, verify cited entries and back up the previous file. Biber 2.20 is downloaded and verified on first use, then reused.
- Fix chapter bibliography paths, included standalone figure initialization and leading math in index capitalization.
- Protect authored prompt fences, reserved markers and layout dimensions. Extract unambiguous prose from fixed-argument xparse commands and ordinary callouts.
- Fit oversized code listings and custom floats together with their captions, and improve scanning performance for book-length sources.

## Validation and limits

Original compilation, source round-trip checks and Chinese layout preflight passed for arXiv **2412.09082v3, 2610.13455v1, 2603.20804v2, 2501.09223v4 and 2510.21890v3**, covering 6,817 paragraphs. Preflight uses synthetic text; it is not a paid full-document translation or a semantic quality evaluation.

The local full regression passed **1,265 backend tests with 3 environment-dependent skips**, plus **32 frontend tests**, builds, resource verification and lint checks. Actual PostScript drawings still require pre-conversion to PDF. Missing code caches or reference data remain explicit errors; existing source glyph warnings are retained.

## Upgrade

Install **1.2.8**, restart TeXGlot or the local service, and choose **Resume / Retry** on failed tasks. Prepared sources are refreshed while valid translations remain reusable under the existing cache rules.

The Zotero plugin remains at **1.0.0**, with its XPI and update manifest included. Plugin users receive these fixes by updating the TeXGlot application or core service.
