# TeXGlot 1.2.7 · Custom gateway request headers

**English** · [简体中文](v1.2.7_CN.md)

This release adds optional HTTP headers for OpenAI-compatible model gateways, addressing [Issue #6](https://github.com/Mengqi-Lei/texglot/issues/6).

## Changes

- Configure a JSON object under **Translation settings → Advanced settings → Extra headers**. Connection tests and model translation requests use the same configuration.
- Validate header names and values, reject reserved headers and control characters, and bound header count and size. Trim outer spaces from pasted values.
- Keep saved values hidden, with explicit replace, discard and clear controls. Editing the service address clears the header draft; saved service profiles restore only their own headers.
- Redact credentials in diagnostics and keep them out of task exports. Existing translation caches and Zotero task reuse remain compatible. DeepL continues to use its separate settings.

## Validation

Local verification passed **1,196 backend tests (3 environment-dependent skips)** and **32 frontend tests**, production build and lint checks. Browser interaction, English/Chinese labels, narrow layouts, a local HTTP gateway and real Tectonic Chinese PDF compilation were verified. A Windows test encoding issue found by CI was corrected with explicit UTF-8. No contributor production gateway credentials were used.

## Upgrade

Install **1.2.7** and restart TeXGlot or its local service. Open the advanced translation settings, enter the headers required by your gateway, test the connection, then save.

The Zotero plugin remains at **1.0.0**. Its existing XPI and update manifest are included; Zotero users should update the TeXGlot app/core.
