# TeXGlot 1.2.4 · 编译恢复与 PDF 插图修复

[English](v1.2.4.md) · **简体中文**

修复两类会在翻译开始前中断任务的问题：未使用的 minted 宏包要求 shell-escape，以及 PDF 插图存在但因内部索引损坏而无法载入。相关报告：[Issue #2](https://github.com/Mengqi-Lei/texglot/issues/2)、[Issue #3](https://github.com/Mengqi-Lei/texglot/issues/3)。

## 更新内容

- 根据实际编译报错检查工程，确认未使用 minted 后移除其显式加载项；实际使用了代码环境、相关命令或冻结缓存时保留源码，并给出处理提示。外部命令执行仍保持禁用。
- 对编译器明确报错、且确认是索引损坏的 PDF 插图尝试修复。保留 `.texglot-original` 备份，并核对页面尺寸、旋转及绘制内容；不删除插图、不生成占位图，也不将矢量图转成位图。
- 区分插图缺失、无法访问、格式损坏、加密及无法自动修复，并提示具体文件和处理方法。
- 图片恢复与宏包配置恢复分别计数，避免多张问题图片耗尽原有配置修复机会；所有恢复次数均有上限。
- 发布用原生检查加入未使用 minted 与三张损坏 PDF 插图的组合用例。

## 验证与限制

两篇真实论文 `2511.01268` 和 `2603.21654` 已恢复原文编译，并通过合成中文排版预检；本轮没有调用付费翻译 API，也未进行全文译文质量评测。对后者的 `fig_1.pdf`、`fig_12.pdf`、`fig_13.pdf`，修复前后的图片渲染像素完全一致。本轮下载的 arXiv v1 源码包含 `fig_13.pdf`，未复现报告中的缺图判断。

macOS 完整后端测试 **992 项通过、3 项跳过**。原模板的非致命警告仍会显示：`2511.01268` 存在乘号字形警告，`2603.21654` 的原文存在长浮动体警告；这些不属于本次已消除的编译中断。独立 XeLaTeX 的原生运行未在这台 Mac 上验证；真实论文使用内置 Tectonic（XeTeX 引擎）测试。

## 升级与恢复

安装 **1.2.4** 后退出并重新打开应用或服务，失败任务可直接点击**继续 / 重试**。无需删除或重新导入论文。已有设置、文献库、批注与有效缓存继续保留。

Zotero 插件仍为 **1.0.0**，XPI 与上一版相同；插件用户只需升级 TeXGlot 应用／核心。
