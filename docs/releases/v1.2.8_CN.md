# TeXGlot 1.2.8

本版改进长篇论文和书籍的 LaTeX 兼容性，统一处理代码缓存、参考文献、正文提取和浮动体排版问题。

## 更新

- 按编译诊断使用固定版本的官方宏包，兼容 minted 3 冻结代码缓存，并补齐 PSTricks、biblatex 依赖。保留工程自带宏包、代码和图形，不开启 shell escape。
- 参考文献缓存过期时，可按本地 BibTeX 数据重建并逐项核对引用，保留旧文件备份。首次需要时自动下载并校验 Biber 2.20，后续复用。
- 修复分章节参考文献路径、被包含的 standalone 图文件初始化，以及索引首部公式的大小写处理。
- 保护作者提示词中的代码围栏、保留标记与排版长度参数；识别固定参数 xparse 命令和普通提示框中的明确正文，减少遗漏。
- 整体缩放过高的代码清单及自定义浮动体，连同标题一起保留；改善长源码扫描性能。

## 验证与边界

已对 arXiv **2412.09082v3、2610.13455v1、2603.20804v2、2501.09223v4、2510.21890v3** 完成原文编译、源码还原检查与中文排版预检，共 6817 个段落。中文预检使用合成文本，不代表付费模型全文翻译或语义质量评测。

本机完整回归为 **1265 项后端测试通过、3 项环境相关跳过**，前端 **32 项测试通过**，构建、资源校验和代码检查通过。真实 PostScript 绘图仍需预先转成 PDF；缺失的代码缓存或引用数据仍会明确报错。原工程已有的字形警告会保留。

## 升级

安装 **1.2.8** 并重启 TeXGlot 或本地服务，然后在失败任务中选择“继续 / 重试”。程序会刷新预处理源码，按原有规则复用有效译文缓存。

Zotero 插件仍为 **1.0.0**，继续附带插件包及更新清单；插件用户更新 TeXGlot 主程序或核心服务即可获得本轮修复。
