# TeXGlot 1.2.4 · Compilation recovery and PDF figure repair

**English** · [简体中文](v1.2.4_CN.md)

Recover two failures that can stop a paper before translation starts: an unused minted package requiring shell-escape, and an existing PDF figure with a corrupt internal index. Related reports: [Issue #2](https://github.com/Mengqi-Lei/texglot/issues/2), [Issue #3](https://github.com/Mengqi-Lei/texglot/issues/3).

## Changes

- Following an actual compilation failure, remove explicit minted package loads only when the project has no detected use. Preserve used code environments, related commands and frozen caches, and provide actionable guidance. External command execution remains disabled.
- Repair only compiler-diagnosed PDF figures with confirmed index corruption. Preserve a `.texglot-original` backup and check page geometry, rotation and drawing content. Figures are neither removed nor replaced with placeholders or rasterized.
- Distinguish missing, inaccessible, corrupt, encrypted and unrecoverable figures, with filenames and recovery guidance.
- Track image repairs separately from package-configuration repairs so several damaged figures do not exhaust the existing configuration-recovery budget. All recovery attempts remain bounded.
- Extend native release checks with an unused minted package and three damaged PDF figures in one project.

## Validation and limits

Both real papers, `2511.01268` and `2603.21654`, now compile their original source and pass synthetic Chinese typesetting preflight. No paid translation API was called, and this was not a full translation-quality assessment. Rendering the latter paper's repaired `fig_1.pdf`, `fig_12.pdf` and `fig_13.pdf` produced pixels identical to the originals. The downloaded arXiv v1 source includes `fig_13.pdf`; the reported missing file was not reproduced.

The full macOS backend suite passed **992 tests, with 3 skipped**. Nonfatal source-template warnings remain visible: a multiplication-sign glyph warning in `2511.01268`, and a long-float warning in the original `2603.21654` document. These are separate from the resolved compilation failures. Standalone XeLaTeX was not available for native verification on this Mac; the real papers were tested using bundled Tectonic (the XeTeX engine).

## Upgrade and recover

Install **1.2.4**, then quit and reopen the app or local service. Failed tasks can use **Resume / Retry** without deletion or reimport. Existing settings, papers, annotations and valid caches are retained.

The Zotero plugin remains **1.0.0**, with the same XPI as the previous release. Plugin users only need to update the TeXGlot app/core.
