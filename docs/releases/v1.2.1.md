# TeXGlot 1.2.1 · DeepL translation

**English** · [简体中文](v1.2.1_CN.md)

TeXGlot now supports DeepL as an independent translation engine. Translate LaTeX papers through the DeepL API from the desktop app, CLI or Zotero integration without configuring an LLM.

## Changes

- Protect formulas, citations and LaTeX structure with validated XML placeholders. When a translation changes protected structure, use bounded recovery before accepting the result.
- Support DeepL API Free and Pro endpoints, source-language selection and optional existing DeepL glossary IDs. Free keys ending in `:fx` automatically use the Free endpoint.
- Report character usage separately from LLM tokens. Keep paragraph caches separate by translation engine, and retain completed work across retries.
- Handle rate limits, temporary failures and exhausted quotas with actionable errors and bounded retries.
- Replace letter placeholders with locally bundled Qwen, DeepSeek and DeepL brand icons in translation settings.

## Start using DeepL

1. Upgrade to TeXGlot **1.2.1**, then quit and reopen the app or local service.
2. Open **Translation settings → DeepL**, enter your own DeepL API key, test the connection and save.
3. Start a new translation. CLI users can select `--provider deepl`; see the [CLI guide](../cli.en.md).

A DeepL API account is required; a website translation subscription alone is not an API key. Existing settings, papers, caches and annotations remain in your data directory. Zotero continues to reuse matching completed translations first; use its explicit retranslation command when you want a new result from a different engine.

The Zotero plugin remains **1.0.0**, with the same XPI as the previous release. Existing plugin users only need to upgrade the TeXGlot app/core for DeepL. See the [plugin guide](../../integrations/zotero/README.md).
