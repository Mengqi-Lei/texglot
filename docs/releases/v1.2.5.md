# TeXGlot 1.2.5 · ACM template compatibility and translation output cleanup

**English** · [简体中文](v1.2.5_CN.md)

This release restores compilation of affected ACM templates and cleans explicit reasoning envelopes from model responses before they reach translations or caches. Thanks to [origin-meta](https://github.com/origin-meta) for the report and contribution in [Issue #4](https://github.com/Mengqi-Lei/texglot/issues/4) and [PR #5](https://github.com/Mengqi-Lei/texglot/pull/5).

## Changes

- Resolve the known Libertinus math font filename mismatch while preserving project-supplied fonts, explicit font lookup rules and source examples.
- Recover confirmed amssymb / unicode-math conflicts using actual compiler load records and a conditional package call. Preserve cross-file code examples, package options/order and the author's non-Unicode-math branch.
- Remove explicit leading reasoning blocks and complete answer envelopes from LLM responses. Preserve tags quoted in the source, JSON string contents and whitespace next to formulas. Incomplete or ambiguous responses enter bounded repair attempts.
- Clean and validate old LLM cache entries, atomically save successful cleanup and retranslate only invalid entries. DeepL keeps its provider-specific processing.
- Refresh older prepared sources on retry while reusing valid translations. Add matching English diagnostics and combined native release checks.

## Validation

Local macOS verification passed **1,082 backend tests, with 3 skipped**, **25 frontend tests** and lint/build checks. The skipped cases require standalone XeLaTeX or Windows. The native release check now combines font recovery, code-example preservation, reasoning cleanup and the previous minted/PDF-figure recovery cases.

The reported paper `2504.07717` compiles to a 12-page original PDF without warnings. Its synthetic Chinese typesetting probe covers 77 segments and produces 11 pages without warnings. Real Tectonic compilation with a mock translation endpoint verifies clean PDFs, source exports and caches. These checks do not call paid translation APIs or assess a model's full-paper translation quality.

## Upgrade

Install **1.2.5**, then quit and reopen TeXGlot or its local service. Use **Resume / Retry** on affected tasks. Source preparation and recognized cached response envelopes are updated while valid translations are reused.

The Zotero plugin continues at **1.0.0**. Its existing XPI is included for installation and the plugin update feed. Zotero users should update the TeXGlot app/core.
