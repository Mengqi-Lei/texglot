# TeXGlot 1.2.7 · 自定义网关请求头

[English](v1.2.7.md) · **简体中文**

本版新增 OpenAI 兼容模型网关的额外 HTTP 请求头配置，回应 [Issue #6](https://github.com/Mengqi-Lei/texglot/issues/6)。

## 更新

- 在 **翻译设置 → 高级设置 → 额外请求头** 中填写 JSON 对象，连接测试与正式模型翻译共用配置。
- 校验名称和值，拦截保留头及控制字符，限制条数和长度；自动去除粘贴值首尾空格。
- 已保存值不回显，支持替换、取消修改和清除。手动修改服务地址会清空请求头草稿；切回已保存服务时只恢复该服务自己的配置。
- 错误诊断隐藏凭据，任务导出不包含凭据；保持旧翻译缓存和 Zotero 任务复用兼容。DeepL 继续使用独立设置。

## 验证

本地验证通过 **1196 项后端测试（3 项因环境条件跳过）**、**32 项前端测试**、生产构建及代码检查。已验证浏览器操作、中英文提示、窄屏布局、本地 HTTP 网关及真实 Tectonic 中文 PDF 编译。跨平台 CI 发现的一处 Windows 测试编码问题已改为显式 UTF-8。未使用反馈者的生产网关凭据。

## 升级

安装 **1.2.7** 后重启 TeXGlot 或本地服务，在高级翻译设置中填写网关要求的请求头，测试连接后保存即可。

Zotero 插件仍为 **1.0.0**，继续附带现有 XPI 和更新清单；插件用户只需更新 TeXGlot 应用或核心服务。
