# TeXGlot 1.2.2 · Custom code environment compatibility

**English** · [简体中文](v1.2.2_CN.md)

This release fixes papers failing before translation when a custom code box contains Markdown fences or literal LaTeX examples. Definitions in another source file are now recognized, so papers such as **Harness²** can finish translation while retaining their code and prompt examples.

## Changes

- Recognize explicitly declared tcolorbox listings, listings environments and fancyvrb environments across source files.
- Preserve literal code throughout segmentation, compiler preparation, font compatibility and layout adjustments. Commands printed inside examples no longer influence dependency or abstract extraction.
- Continue translating ordinary prose boxes and keep existing validation of formulas, references, protected markers and model-generated syntax.
- Refresh prepared sources when retrying an older task, while continuing to reuse valid paragraph translations.

## Validation

Complete translations were verified for Harness² (`2610.14224`, 34 pages), Generate-on-Graph (`2404.14741v3`, 20 pages) and SceneTok (`2602.18882`, 30 pages). The latter two were historical failed tasks; their existing compatibility repairs were verified again. All three finished with no remaining failed translation segments. Code-box content and representative rendered pages were checked.

The macOS source validation passed **941 backend tests**, with **3 environment-specific skips**, plus **25 frontend tests** and **19 desktop tests**. Packaged-engine checks include single-file and multi-file LaTeX input with custom literal listings.

## Upgrade

Install **1.2.2**, quit the previous app/service and reopen it. For an existing failed paper, choose **Resume / Retry**; there is no need to delete the task or import the paper again. Saved settings, papers, annotations and valid paragraph caches remain available. Code and prompt listings are preserved in their original language.

The Zotero plugin remains **1.0.0**, with the same XPI as the previous release. Existing plugin users only need to update the TeXGlot app/core.
